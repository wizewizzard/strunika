# Strunika

Гитарная мастерская: аккорды, бой, перебор, перкуссия и личная библиотека композиций.

## Возможности

- Гриф в стандартном строе E A D G B E; смены аккордов внутри такта.
- Размер 4/4, сетки 1/1, 1/2, 1/4, 1/8 и 1/16.
- Четыре синтезированных тембра, щелчок и бочка.
- Прослушивание всех, выбранных или одного такта; темп и зацикливание.
- Регистрация по логину и паролю, вход и выход.
- Сохранение, открытие, копирование и удаление собственных композиций.
- Автор назначается сервером по аккаунту. Композиции приватны для владельца.
- Защита от перезаписи старой версией из другой вкладки.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:4173. Локальная база находится в `work/local-d1/` и не попадает в Git.

```sh
npm run build
npm test
```

Приложение теперь включает сервер: простой раздачи статических файлов недостаточно для аккаунтов и библиотеки.

## Устройство проекта

- `public/` — HTML, CSS, редактор и библиотека на JavaScript.
- `server/` — Cloudflare Worker: API, авторизация, валидация и раздача интерфейса.
- `db/schema.ts` — схема D1/SQLite, `drizzle/` — миграции.
- `scripts/build.mjs` — сборка в `dist/`; статические файлы встроены в Worker.
- `.openai/hosting.json` — текущий проект Sites и логическое подключение `DB`.
- `tests/` — проверки API и прав доступа на изолированной локальной D1.

Sites применяет миграции перед загрузкой Worker. Изменения схемы: `npm run db:generate`. Уже опубликованные миграции не редактировать.

## Аккаунты и сохранение

Логин: 3–32 латинские буквы, цифры или `_` (регистр не учитывается). Пароль: 15–128 символов. Пароли хешируются scrypt с отдельной солью; сессии хранятся в D1 в виде хешей случайных токенов. Cookie: HttpOnly, Secure, SameSite=Lax, срок 14 дней. Для публичного размещения необходим HTTPS. Восстановление пароля по почте пока отсутствует.

Сохранение в аккаунт выполняется кнопкой **«Сохранить в аккаунт»**. Изменения также сохраняются как временный локальный черновик. Старый черновик из версии без аккаунтов остаётся в браузере; после входа его можно сохранить в библиотеку. У каждого аккаунта отдельный локальный черновик. При выходе отображается гостевой черновик.

Черновики привязаны к браузеру и домену, записи в D1 доступны после входа с другого устройства. Лимит первой версии — 200 композиций на автора. API ограничивает попытки входа и проверяет владельца для каждой операции. Экспорт всей базы и резервное копирование управляются средствами платформы хранения.

## Размещение на своей ВМ

Текущая серверная версия использует API Cloudflare D1. Для ВМ потребуется адаптер SQLite/PostgreSQL и серверный runtime; `dist/` нельзя просто раздать Nginx и получить работающую регистрацию.
