# Strunika

Веб-мастерская для создания гитарных партий: аккорды, бой, перебор и перкуссия.

## Возможности

- Интерактивный гриф в стандартном строе E A D G B E.
- Последовательности тактов со сменами аккордов внутри такта.
- Размер 4/4, сетки целых, половинных, четвертных, восьмых и шестнадцатых нот.
- Редактор боя и перебора, бочка и щелчок на отдельных шагах.
- Четыре синтезированных тембра струн.
- Воспроизведение всей композиции, выбранных тактов или одного такта, зацикливание и настройка темпа.
- Автоматическое сохранение текущей композиции в localStorage.

## Локальный запуск

Нужен Python 3 либо любой другой сервер статических файлов:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173 в браузере. Звук включается после нажатия кнопки воспроизведения.

## Размещение

Раздавайте содержимое `dist/` через Nginx, Caddy или другой веб-сервер. Сборка, Node.js, backend и база данных не требуются. Для нового домена настройте HTTPS.

`.openai/hosting.json` содержит идентификатор существующего размещения в Sites; для собственного сервера этот файл не нужен.

## Хранение данных

Композиция хранится только в браузере на текущем устройстве и привязана к адресу сайта. Очистка данных браузера удалит её; при переходе на другой домен она автоматически не переносится. Аккаунтов и облачной синхронизации нет.

## Технологии

HTML, CSS, JavaScript, Web Audio API. Звук синтезируется в браузере, без внешних аудиосэмплов.
